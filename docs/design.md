# MedGuide 设计规范

## 设计方向

**山野健康手记**：面向有健康疑问、需要整理症状与准备就医的普通用户。以真实山湖、林间摄影和舒展的中文排版，让信息更易读、提问更容易开始。品牌保留青绿色系，减少工作台式的细碎边框、技术标识和重复占位。

登录页以左侧内容、右侧账户表单构成主次；对话首页以问题入口为中心，开始对话后呈现真实消息与健康线索。四类入口是身体不适、用药疑问、检查解读、就医准备。模板只填写可编辑草稿，不自动发送、不假设用户的年龄、病史或症状。

中文使用本机 `Noto Sans SC / Microsoft YaHei / PingFang SC`，英文品牌使用 `Segoe UI`。运行时无需第三方字体请求。登录主标题随视口约 29–62px，首页标题约 27–49px，消息正文 13–14px。长消息和资料字段允许换行，不截断风险说明。

## 布局与组件

- 延用 React、原生 CSS、`lucide-react`，不引入第二套组件库。
- 桌面为轻量会话侧栏、主对话区和健康线索区；主工作区使用 22px 圆角，输入/按钮使用 10–17px 圆角。
- 1020px 以下使用主对话单列，侧栏通过抽屉打开；抽屉保留焦点循环、Escape 关闭、背景 inert 和触发器焦点恢复。
- 820px 以下登录页为单列，手机优先呈现产品目的与表单，隐藏重复的示例介绍。
- 关键操作具有 hover、focus、active、disabled 状态。动画控制触控区域至少 44×44px，窄屏风景切换也能从会话抽屉访问。
- 加载、服务不可用、空引用、注册校验、真实高风险等状态必须可辨识，不能用“演示正常”替代真实故障。

## 本地摄影与动态

`frontend/public/landscapes/` 包含两张 2000×1333 WebP 摄影：山湖与森林。文件合计约 924 KiB，摄影师、原页、许可及变换记录在该目录的 `SOURCES.md`。页面不热链摄影，不放宽 CSP。

共享的 `ScenicAtmosphere.tsx` 与 `scenery.css` 负责：

- 背景使用薄荷绿、雾蓝、淡米白三种接近的浅色，36 秒缓慢循环渐变，首尾一致，无跳色。通过独立渐变层的透明度与位移过渡，不逐帧改写背景色。
- 图片层以约 0.14 的透明度作为淡底纹，并叠加轻薄浅色遮罩，让渐变色彩成为背景主体，正文区域保持清晰。
- 40 秒全景轻移、18/24 秒雾气漂移、少量柔光和浮光。图标使用低速轻摆，鼠标不动时也持续运行。
- 风景切换采用 1.6 秒交叉淡变；连续动画只改变 transform / opacity，不逐帧更新 React 状态。
- 用户可暂停或恢复；偏好只存储 `scene` 与 `paused`，不存储健康信息。存储不可用或损坏时安全降级。
- 遵循 `prefers-reduced-motion` 和减少透明度设置。高风险状态自动暂停装饰动态，并将缓和文案替换为紧急就医提醒。
- 装饰层使用 `aria-hidden` 与 `pointer-events: none`，不进入键盘焦点、不遮挡操作。

## 内容边界

风险未评估时必须明确显示未评估。风险状态同时用文字、图标和颜色表示。出现高风险时优先展示紧急就医指引，不提示用户慢慢等待。

资料必须来自真实接口，来源链接沿用白名单校验，保留来源日期和适用的 OGL 声明。消息、引用、状态和反馈继续沿用既有 API、Cookie、SSE 与请求幂等逻辑。

保持隐私提示与“健康信息整理和就医指引，不替代医生诊断、处方或急救服务”的边界，不编造健康资讯、诊断、资料或服务在线状态。

## 验收

前端执行 `npm test` 和 `npm run build`，并验证既有同源 Cookie/CSP 契约。浏览器覆盖登录/注册、桌面和手机、模板填入与编辑、消息/引用/反馈、高风险、移动抽屉焦点、持续动态/暂停/减少动态以及本地摄影加载。使用接口夹具进行界面验证时，明确区分示例状态与真实模型能力。
