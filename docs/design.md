# MedGuide 设计规范

## 设计方向

**临床指挥台（Clinical Command Center）**：面向需要快速判断、追问和转介的用户，强调安静、可信、可追溯。界面不是营销页，而是高密度但有节奏的工作台。

## 色彩令牌

- `--ink-950: #17212B`：主文字与导航
- `--ink-700: #40505E`：次级文字
- `--canvas: #F5F7F6`：页面底色
- `--surface: #FFFFFF`：内容表面
- `--teal-700: #167C80`：主操作与可信状态
- `--teal-100: #DDF1F0`：低强调背景
- `--amber-600: #C87925`：需要关注但未升级风险
- `--coral-600: #C94C4C`：高风险提示
- `--line: #DCE3E4`：分隔与边界

禁止使用紫蓝渐变、玻璃拟态和无语义装饰光晕。风险状态必须同时使用文字、图标和颜色表达。

## 排版

- 中文正文：`Noto Sans SC`, `Microsoft YaHei`, sans-serif
- 英文/数据：`IBM Plex Mono`, `Consolas`, monospace
- 页面标题 30/36，模块标题 15/22，正文 14/22，说明 12/18
- 不使用负字距，不让标签在窄屏溢出。

## 布局与组件

- 桌面端三栏：左侧会话与信息摘要，中间整理流，右侧证据与系统状态。
- 移动端改为单列，证据与信息摘要折叠到整理流之后。
- 圆角不超过 8px；卡片只用于重复记录、模态和工具面板，页面分区不套卡片。
- 所有图标按钮使用 `lucide-react`，并提供 `aria-label` 或可见文字。
- 关键状态拥有 loading、empty、error、success 四种表现。

## 交互语气

使用“建议补充”“当前需要排除”“可查询到”等可验证表述。避免“保证”“一定是”“最佳方案”等过度承诺。
