# 评测与质量门槛

## 可重复评测

```powershell
.\.venv\Scripts\python.exe scripts\evaluate.py
```

`data/eval_cases.jsonl` 覆盖疾病与就诊方向、药品、检查、结构化查询、高风险和特殊人群。脚本输出意图、风险、引用覆盖和结构化命中；任一用例失败都返回非零退出码。

## 在线指标

`GET /api/metrics` 返回：

- 平均响应耗时与请求量
- 检索命中率、引用覆盖率
- 高风险请求占比、安全拦截数和结构化查询成功数
- 用户点赞/点踩与带评论反馈
- 经过人工标注后计算的幻觉率

指标按脱敏响应 ID 去重，生产 Redis 负责共享聚合和 TTL。幻觉率在没有人工标签时必须显示为未标注，不能用占位值冒充质量结论。

## 发布门槛

发布前必须提供以下证据：

1. 账户注册、重复用户名、错误密码、注销、Cookie 恢复和 owner 隔离。
2. 高风险分流、确定性诊断拦截、药品动作拦截和安全否定语句回归。
3. 关键实体检索排序、FAQ/科室路由、引用覆盖和 generation 一致性。
4. 请求断线恢复、幂等重试、SSE 节点事件和并发会话更新。
5. OpenAI、Redis、Milvus、MySQL（启用时）和反向代理的真实连通性。
6. 1440px 桌面与 390px 移动视口无溢出、遮挡、焦点陷阱或控制台错误。

单元测试、离线评测、构建成功和 Compose 静态解析只能证明代码层行为，不能代替真实供应商、数据源和网关验收。

## v0.2.0 源码发布验收（2026-09-10）

本次在 Windows / PowerShell 7 环境验证。浏览器使用独立本地 API、SQLite 账户库、内存会话和随仓库提供的15条资料，回答器连接真实模型服务。该组合用于隔离验收，不是生产部署拓扑；界面保留测试模式下的服务受限提示。

| 前端 | `npm test`：7项通过；`npm run build` 成功 |
| 离线评测 | 12例全部通过意图、风险、引用要求和结构化查询要求；只反映固定样例，不代表临床准确率 |

源码发布仍有以下边界：

- 本次没有验收生产TLS入口、Redis、Milvus或启用时的MySQL；生产部署必须按上方发布门槛补齐验证。BM25替代Milvus时也要确认持久化索引与语料generation一致。
- 15条资料是小型验证语料。已读取并补齐7项来源的日期与OGL改编声明，剩余来源和内容授权仍需逐页复核；详见[知识内容与许可](../data/knowledge/README.md)。
- 未进行医学专家审核、真实患者试验、临床性能评估或正式压力测试。新增红旗规则与12例离线评测不构成完整临床安全验证。
- 验收日志、合成账户数据库、截图、模型配置及凭据不属于源码发布内容。
